# Prescripto - Full Stack Doctor's Listing and Appointment Booking platform.

A full-stack Doctor Appointment Booking and Doctor Listing Platform built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). This application allows patients, doctors, and administrators to interact through a secure, role-based system for booking and managing medical appointments.

## 👤 Patient
- Register & login securely
- Browse doctors and view profiles
- Book appointments with doctors
- Pay appointment fees online
- View & manage booked appointments

## 🧑‍⚕️ Doctor
- Login to doctor dashboard
- View upcoming appointments
- Track earnings
- Update personal profile and availability

## 🛠️ Admin
- Secure admin dashboard
- Manage doctors (add/update/remove)
- Manage all appointments
- Oversee platform activity

## 🧩 Key Features
🔐 Role-based authentication (Patient, Doctor, Admin)
📅 Appointment booking & management
💳 Online payment gateway integration
📊 Doctor earnings dashboard
☁️ Cloud image upload (doctor profiles)
🧠 Secure JWT-based authentication
📱 Responsive UI using Tailwind CSS
🌐 Deployed on cloud (Render & MongoDB Atlas)

## 🛠️ Tech Stack Used
- Frontend: React, React Router, Context API, Axios, Tailwind CSS
- Backend: Node.js, Express, Mongoose, JWT, Bcrypt
- Database: MongoDB Atlas
- Cloud Services: Cloudinary (image storage)
- Deployment: Vercel (frontend), Vercel (backend), MongoDB Atlas (database)
